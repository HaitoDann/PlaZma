📝 Exemple de Code

Comment utiliser ces boutons dans ton code ?

Copie-colle simplement le code HTML du bouton que tu veux utiliser. Les styles sont déjà chargés via theme.css.

<!-- Exemple avec le bouton Cœur --> <button class="pz-heart-btn" type="button" aria-label="Ajouter aux favoris"> <svg class="pz-heart" viewBox="0 0 24 24" width="18" height="18" fill="none" stroke="currentColor" stroke-width="2"> <path class="pz-heart-path" d="M20.84 4.61a5.5 5.5 0 0 0-7.78 0L12 5.67l-1.06-1.06a5.5 5.5 0 0 0-7.78 7.78l1.06 1.06L12 21.23l7.78-7.78 1.06-1.06a5.5 5.5 0 0 0 0-7.78z"/> </svg> </button>

Note : Assure-toi que la classe CSS du bouton (pz-heart-btn) et les classes des éléments SVG (pz-heart, pz-heart-path) sont correctement appliquées pour que les animations fonctionnent.
